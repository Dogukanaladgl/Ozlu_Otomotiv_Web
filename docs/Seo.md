# SEO Strategy

## Objective

Build a technically sound, useful and locally relevant website for Özlü Otomotiv.

The website should be capable of targeting relevant Hyundai, Kia and original used spare-part searches, particularly searches with local intent around Konya.

No specific ranking position can be guaranteed.

---

## SEO Philosophy

Optimize for real users and search intent.

Do not optimize by mechanically repeating keywords.

The website should provide:

- Useful content
- Clear page topics
- Strong technical foundations
- Semantic HTML
- Logical internal linking
- Good mobile UX
- Good performance
- Accurate local business information

---

## Primary Search Intent

The dominant intent is expected to be:

Commercial + Local

Example user need:

> I need a Hyundai/Kia spare part and want to find a supplier, ask about a part or contact a business.

## Information Architecture

Initial production routes:

`/`

`/hyundai-yedek-parca`

`/kia-yedek-parca`

`/cikma-yedek-parca`

`/parca-sorgula`

`/hakkimizda`

`/iletisim`

Do not create model/location pages simply because a keyword exists.

Additional landing pages should only be introduced when:

1. The business genuinely serves that topic.
2. Useful unique content can be provided.
3. Search/user data justifies the page.

---

## Homepage

The homepage should establish:

- Özlü Otomotiv
- Hyundai specialization
- Kia specialization
- Original/new and original used spare parts
- Konya / Selçuklu
- Spare-part inquiry
- Contact methods

The homepage should not attempt to rank for every possible query by stuffing content.

---

## Hyundai Page

Route:

`/hyundai-yedek-parca`

Primary topic:

Hyundai spare-part services.

The page should provide useful Hyundai-specific information without inventing:

- Supported models
- Inventory
- Prices
- Availability

---

## Kia Page

Route:

`/kia-yedek-parca`

Primary topic:

Kia spare-part services.

Do not create a copy of the Hyundai page with only brand names replaced.

Provide genuinely relevant structure/content.

---

## Used Parts Page

Route:

`/cikma-yedek-parca`

Potential useful topics:

- What an original used/dismantled part is.
- Why correct part identification matters.
- Why vehicle/model/VIN information is useful.
- How customers can submit an inquiry.

Avoid unsupported claims about quality, warranty or stock.

---

## Spare-Part Inquiry Page

Route:

`/parca-sorgula`

Primary purpose:

Conversion.

The page should clearly explain:

- What information is needed.
- Why relevant vehicle information is requested.
- How the user submits the request.
- What happens after submission, without promising unverified response times.

---

Homepage

## Semantic HTML

Use HTML according to meaning.

Prefer appropriate:

- `header`
- `nav`
- `main`
- `section`
- `article` where appropriate
- `address`
- `footer`

Use logical heading hierarchy.

Do not use heading levels merely for visual styling.

---

## Metadata

Each indexable page should have useful page-specific:

- Title
- Description
- Canonical information where appropriate
- Open Graph metadata where appropriate

Avoid duplicated boilerplate metadata when page-specific information can be provided.

---

## Structured Data

Implement structured data only when it accurately describes visible, verified information.

Do not fabricate:

- Reviews
- Ratings
- Prices
- Inventory
- Availability
- Opening hours
- Coordinates
- Business claims

Structured data must not contradict visible content.

---

## Images

Use real business imagery when available.

Images should:

- Use appropriate dimensions.
- Be optimized.
- Have useful alt text when informative.
- Use empty alternative text when genuinely decorative.

Do not stuff keywords into alt text.

---

## Technical SEO Checklist

Before production release verify:

- Indexable pages
- Page titles
- Meta descriptions
- Canonical handling
- Heading hierarchy
- Semantic HTML
- Image alt strategy
- Internal links
- Sitemap
- Robots configuration
- Structured data
- HTTPS
- Mobile usability
- Performance
- Broken links
- 404 behavior
- Search Console readiness

---

## Post-Deployment

After production deployment:

1. Verify the production domain.
2. Verify HTTPS.
3. Check robots behavior.
4. Check sitemap.
5. Add/verify the property in Google Search Console.
6. Submit/discover sitemap through Search Console.
7. Inspect important URLs.
8. Monitor indexing.
9. Monitor search queries and impressions.
10. Use real search data to guide future content expansion.

Do not create new SEO pages based solely on guesses when real Search Console data becomes available.
